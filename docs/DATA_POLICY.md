# 数据与来源规则

## 两种收录

参数档案记录人工核验过的具体版本，允许字段未知。框架索引记录官方目录引用，包含第三方量化、独立草稿与占位页；索引数量不代表参数档案完整数量。

## 可接受的来源

模型开发方官网、经核实的官方发布账号、对应仓库配置与作者报告；SGLang/vLLM官方资料作为框架证据单列。聚合网站可帮助发现型号，但不能替代字段的原始出处。

Hugging Face来源尽量固定到提交；在线发布页保留URL和实际核验日期。监测只记录“观察到的提交/页面变化”，不会自动宣称重新核验。

## 参数范围

作者主模型公布值、全部checkpoint张量统计、语言/视觉组件、独立草稿与MTP参数可能采用不同范围。不得简单互换，也不得用总参数乘专家比例估算整模型激活量。量化打包、scale、共享张量和多模态组件也会影响计数。

官方明确等结构或组件关系时可有限推导，必须保留前提、来源链、范围和限制。闭源API只登记已公布的规格，不从名称相近的开放权重推断结构。

## 框架支持

支持等级分别为具体部署示例、支持表具体示例、官方模板选项、架构已列、草稿配置引用、混合服务架构、仅目录占位与所查页面未列。相同架构不能证明所有checkpoint、量化、硬件、MTP与功能组合都可用。`latest`文档不代表所有已安装版本。

当前资料未进行模型推理实测；配置声明、官方部署示例和本机运行结果应分别表达。

## 日期

`checked`用于事实核验；`data/watch-state.json`的`observedAt`用于自动来源观察。2026-10-16新增开源与维护功能，不改变2026-10-15事实快照日期。
