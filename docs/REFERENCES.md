# 参考项目

本项目从下列项目的功能和公开设计中获得参考，当前代码在既有Model Atlas实现上独立整理，没有复制这些项目的源码或整套数据。

- [LLM Explorer](https://github.com/isEmmanuelOlowe/llm-explorer)：固定版本配置读取、来源与计算/估算分开、架构展示。
- [Frontier ML](https://frontiermlnp.com/models)：架构、专家与上下文的并排比较。
- [LLMDB](https://llmdb.com/models)：模型资料与资源链接的组织方式。
- [models.dev](https://github.com/anomalyco/models.dev)：可复用的结构化模型目录与API数据分离。
- [llmfit](https://github.com/AlexsJones/llmfit)：模型精度与本地部署适配信息的分类。

模型事实仍回到开发方官方模型卡、配置、报告；框架证据来自[SGLang](https://docs.sglang.io/cookbook/autoregressive/intro)与[vLLM](https://docs.vllm.ai/en/latest/models/supported_models/)。逐字段原始URL保存在数据中。
